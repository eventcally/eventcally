# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| Latest release (see the Releases page) | Yes |
| `main` | Yes |
| Older releases | No, please upgrade |

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for security problems.

Use GitHub private vulnerability reporting instead: open the repository's **Security** tab
and choose **Report a vulnerability**, or go directly to
<https://github.com/eventcally/eventcally/security/advisories/new>.

Please include:

- the affected version or commit
- steps to reproduce
- the impact you expect

## What to expect

We aim to acknowledge your report within 7 days (best effort). Fixes and disclosure are
coordinated through a GitHub Security Advisory, and we credit reporters on request.
